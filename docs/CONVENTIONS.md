# ファイル命名・フォルダ規約

案件（ジャンル）× 成果物種別 × 日付 の3軸で決める。迷ったら「後から grep できるか」で判断する。

## フォルダ

```
projects/<ジャンル slug>/     案件ごとの成果物
docs/                        規約・ナレッジなど案件横断のもの
tools/                       スクリプト類
```

ジャンル slug は英小文字ハイフン区切り（`camera-kaitori`, `gold-kaitori`, `takushoku`）。
日本語ジャンル名との対応は本ファイル末尾の対応表に追記していく。

## ファイル名

```
<YYYY-MM-DD>_<成果物種別>.<ext>
```

- 日付は**データの対象日ではなく作成日**。対象期間はファイル冒頭に書く。
- 成果物種別は下の語彙から選ぶ。新しい種別を足すときはこの表にも足す。

| 成果物種別 | 中身 |
|---|---|
| `search-query-report` | 検索語句レポートの分析結果 |
| `negative-keywords` | 除外キーワード案（入稿用） |
| `keywords` | 追加キーワード案（入稿用） |
| `rsa-copy` | RSA見出し・説明文 |
| `campaign-design` | キャンペーン設計書 |
| `persona` | ペルソナ設計 |
| `pl-simulation` | 粗利・収支シミュレーション |
| `genre-research` | ジャンル調査 |

## やらないこと

- `最終`, `修正版`, `_v2` のような世代を名前に入れない。日付が世代を表す。
- 同じ内容を別フォルダにコピーしない。参照はパスで書く。
- ルート直下にファイルを置かない。必ずどれかのフォルダに入れる。
